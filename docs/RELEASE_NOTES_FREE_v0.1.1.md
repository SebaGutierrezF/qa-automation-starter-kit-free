# QA Automation Starter Kit — Community Free v0.1.1 (Alpha)

The first public distribution of **QA Automation Starter Kit Community Free**, an MIT-licensed Python learning project for local QA automation on Windows.

### Included
- 4 executable examples: **2 API tests** and **2 Selenium UI tests**.
- Local HTTP demonstration shop bound to **127.0.0.1**.
- Reusable API client, Selenium browser helper and introductory Page Object example.
- Source code, a package manifest, Windows PowerShell setup and verification scripts.

### Installation
Download the attached **qa-automation-starter-kit-free-v0.1.1.zip**, extract it, and follow the README inside the archive.

**Requirements:** Windows 10/11, Python 3.12, PowerShell, pytest 8.3.4, Selenium 4.28.1, Google Chrome and a compatible ChromeDriver. Dependencies, wheels, Chrome and ChromeDriver are **not bundled**; offline setup will not fetch them automatically.
